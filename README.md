
# 🌱 AgroSmart - Agricultura Inteligente

## Sobre o projeto

O AgroSmart é um aplicativo desenvolvido para ajudar pequenos agricultores a organizar e acompanhar suas plantações.

O projeto utiliza tecnologia para facilitar o gerenciamento agrícola e incentivar práticas sustentáveis.

## 🎯 Objetivo

Desenvolver uma ferramenta digital simples e acessível que auxilie pequenos agricultores no controle de plantações e irrigações.

## 🚀 Funcionalidades

- Cadastro de plantações.
- Controle de irrigação.
- Histórico de atividades.
- Orientações sobre cuidados com as culturas.
- Relatórios agrícolas.
- Armazenamento de informações no navegador.

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 🌾 Público-alvo

Pequenos agricultores.

## 🌍 Importância ambiental

O AgroSmart busca incentivar o uso consciente da água, o planejamento agrícola e a sustentabilidade no campo.

## 📱 Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo index.html no navegador.
4. Comece a cadastrar suas plantações.

## 🔬 Projeto de feira de ciências

Este aplicativo é um protótipo educacional de agricultura inteligente.

Os dados são inseridos manualmente pelo usuário. O sistema não utiliza sensores físicos.
